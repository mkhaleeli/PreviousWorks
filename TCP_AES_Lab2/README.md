# Lab 2



This is a AES-256 Symmetric Encryption between a "client" and "server" on the same machine, running in separate command-lines executions. Communicating through the use of sockets. 





* ServerTCP.py is the receiver which must be initially established before being ran in the command terminal
* ClientTCP.py is the initializer which must be ran after the server is established, within the command terminal 
* data.txt is the temporary data file for which the message is transmitted between both programs, rewritten depending on the sender and recipient, shown in the header.
